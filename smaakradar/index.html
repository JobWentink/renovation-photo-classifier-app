    Google API-sleutel

    Hoe kom ik aan een sleutel? (5 minuten)
    1. Ga naar Google Cloud Console → Google Maps Platform en maak een project.
    2. Zet Places API (New) aan.
    3. Maak bij Keys & Credentials een API-sleutel.
    4. Beperk de sleutel: Website restrictions met jouw domein (bijv. https://jouwnaam.github.io/*) en API restrictions op alleen Places API (New).
    5. Plak hem hierboven. De sleutel blijft alleen op dit apparaat.

    Google geeft elke maand een flink gratis tegoed. Eén zoekopdracht kost 2 tot 9 aanvragen. Smaakradar onthoudt resultaten tijdens je sessie, zodat je niet dubbel betaalt.

    Jouw gegevens

    Je afvinklijst staat alleen op dit apparaat. Maak een backup om hem op je telefoon, tablet of laptop te zetten.
